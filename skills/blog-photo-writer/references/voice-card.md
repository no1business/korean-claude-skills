# 내 말투 카드 (양식)

예전 블로그 글 2~3개를 읽고 아래 칸을 채운다. 예시는 실제 글에서 그대로 가져온다 (지어내지 않는다).

```
[내 말투 카드]
- 문장 끝: (예: ~했어요 / ~더라고요 / ~인 듯?)
- 한 문단 길이: (예: 1~2줄, 줄바꿈 자주)
- 자주 쓰는 말: (예: 진짜, 완전, 살짝, 솔직히)
- 웃음·감정 표현: (예: ㅎㅎ 자주, ㅋㅋ 가끔, ㅠㅠ 거의 안 씀)
- 이모지 습관: (예: 소제목마다 하나, 본문엔 거의 없음)
- 도입 습관: (예: 날씨·기분 이야기로 시작)
- 마무리 습관: (예: "다음에 또 올게요!" 같은 재방문 한마디)
- 안 쓰는 말: (예: 존댓말 '~습니다'체, 과한 감탄)
- 예시 문장 3개: (실제 글에서 그대로)
```

카드를 만든 뒤에는 "이 카드를 프로젝트 지시사항에 붙여두면 다음부터는 사진이랑 메모만 주시면 돼요"라고 안내한다.
