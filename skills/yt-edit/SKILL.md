# yt-edit

모든 결과물은 한국어로 쓴다. 한국 유튜브 시청자 기준으로 쓰고, 영어 예시는 한국 상황으로 바꾼다.

타임스탬프가 있는 자막으로 편집 목록을 만든다. 도구는 잘라낼 곳을 출력한다. 적용은 사용자가 한다.

```bash
python3 deadair.py transcript.srt              # srt, vtt or whisper json
python3 deadair.py transcript.srt --floor 0.35 --json
```

아직 자막이 없나? 달라고 하거나 먼저 만든다. `whisper`, `faster-whisper`, 또는 일부 공개로 올렸을
때 유튜브가 자동으로 만드는 자막 트랙 모두 된다. 타이밍을 추측하지 않는다.

## 찾는 것

- **DEAD** - 기준(floor)보다 긴 공백. 가운데를 잘라서 양쪽에 숨 쉴 틈을 남긴다. 말에 딱 붙여
  자르면 다듬은 영상이 숨 가쁘게 들린다.
- **FILLER** - 군말만 있는 자막 줄. 예: "음", "어", "그러니까" (원본 기준 예시는 "um", "so yeah",
  "basically").
- **REPEAT** - 다시 시작한 문장. 바로 앞 자막 줄이 아니라 실제로 말이 있었던 마지막 줄과
  비교한다. 다시 찍은 부분은 대개 두 시도 사이에 "음"이 끼어 있기 때문이다.

## 하지 않는 것

영상 파일은 건드리지 않는다. B롤에 대한 의견도 없다. 보고서의 40% 컷은 말소리의 40%다. 영상에
말 없는 긴 시연 장면이 있으면 그 숫자는 틀린다. 맨 아래 러닝타임을 믿기 전에 보고서를 실제
영상과 맞춰 본다.

## 마지막 관문

여기서는 아무것도 게시되지 않는다. 이 스킬은 쓰기만 하고, 게시는 사용자가 한다. 모든 결과물은
사용자가 복사할 수 있는 블록으로 끝나고, 매번 마지막 줄은 이 질문이다: **이대로 올릴까요, 고칠까요?**
