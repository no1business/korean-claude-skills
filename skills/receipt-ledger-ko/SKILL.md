# 영수증 → 간편장부 (한국판)

1인 사업자·소상공인이 영수증 사진만 올리면 간편장부 엑셀을 만들어 주는 스킬이다. 세 단계로 일한다.

1. **영수증 읽기**: 사진을 한 장씩 직접 보고 날짜·거래처·금액·결제수단을 뽑는다.
2. **장부 정리**: 계정과목을 나누고 월별 합계가 들어간 엑셀(`장부_YYYYMM.xlsx`)을 만든다.
3. **빠진 경비 찾기**: 카드 내역 파일을 주면 장부와 대조해 장부에 없는 결제와 영수증만 있고 카드에는 없는 건을 찾아낸다.

답은 항상 한국어 존댓말로, 짧게 한다.

## 1단계: 영수증 읽기

- 올린 순서대로 1번부터 번호를 붙인다.
- 사진마다 아래 값을 읽는다. 읽을 수 없는 값은 지어내지 말고 빈칸으로 두고 `확인필요`에 이유를 쓴다.
  - `date` 거래일 (YYYY-MM-DD)
  - `vendor` 거래처(상호)
  - `item` 거래 내용(대표 품목 한 줄, 예: "아메리카노 2잔", "프린터 토너")
  - `amount` 합계 금액(원, 숫자만). 할인 후 실제 결제 금액을 쓴다.
  - `vat` 부가세가 영수증에 따로 적혀 있으면 그 금액, 없으면 비움
  - `pay` 결제수단: 카드 / 현금 / 계좌이체 / 모름
  - `card_last4` 카드 끝 4자리가 보이면(그 외 카드번호는 절대 적지 않음)
  - `proof` 증빙 종류: 카드전표 / 현금영수증 / 간이영수증 / 세금계산서 / 기타
  - `account` 계정과목 (아래 표에서 고름)
  - `check` 확인이 필요한 이유(흐림, 금액 두 개, 날짜 잘림, 개인 지출 의심 등)
- 같은 영수증이 두 번 찍혔으면(날짜·거래처·금액이 같음) 하나만 남기고 `check`에 "중복 의심"을 쓴다.
- 흔들리거나 반쯤 접힌 영수증도 최대한 읽되, 숫자가 확실하지 않으면 `check`에 적는다.
- 카드번호 전체, 사업자등록번호, 승인번호 같은 민감 정보는 장부에 옮기지 않는다.

### 계정과목 (간편장부용, 하나만 고름)

| 계정과목 | 예시 |
|---|---|
| 상품·원재료 매입 | 팔려고 사 온 물건, 재료 |
| 복리후생비 | 직원 식대·간식·음료 |
| 여비교통비 | 택시, 기차, 출장 숙박, 주차 |
| 차량유지비 | 주유, 수리, 세차, 통행료 |
| 기업업무추진비 | 거래처 식사·선물 (예전 이름: 접대비) |
| 소모품비 | 10만 원 미만 소모성 물품, 생활용품 |
| 사무용품비 | 문구, 복사용지, 토너 |
| 도서인쇄비 | 책, 인쇄, 명함, 현수막 |
| 통신비 | 휴대폰, 인터넷, 우편 |
| 광고선전비 | 광고비, 홍보물, 체험단 |
| 지급수수료 | 각종 수수료, 구독료, 플랫폼 수수료 |
| 임차료 | 사무실·매장 월세 |
| 수도광열비 | 전기, 가스, 수도 |
| 교육훈련비 | 강의, 교육 |
| 기타 | 위에 없는 것 |

- 마트 영수증처럼 품목이 섞이면 금액이 큰 쪽 기준으로 고르고 `check`에 "품목 혼합"이라고 쓴다.
- 술집·주말 마트·개인 의류처럼 사업과 관련 없어 보이는 지출은 장부에 넣되 `check`에 "개인 지출 의심"이라고 쓴다. 비용 인정 여부를 클로드가 단정하지 않는다.

## 2단계: 장부 엑셀 만들기

1. 읽은 결과를 `receipts.json`(목록, 위 키 그대로)으로 저장한다.
2. 스킬 폴더의 `scripts/make_ledger.py`를 실행한다.

```
python scripts/make_ledger.py receipts.json 장부.xlsx
```

3. 만들어진 엑셀 파일을 사용자에게 준다. 시트는 세 개다.
   - **장부**: 일자 · 거래처 · 거래내용 · 계정과목 · 금액 · 부가세 · 결제수단 · 증빙 · 확인필요
   - **월별 합계**: 월 × 계정과목 합계, 월 합계
   - **확인필요**: `check`가 있는 줄만 모은 목록
4. 대화창에는 한 줄 요약만 쓴다. 예: "영수증 6장 → 장부 6줄, 합계 182,400원, 확인 필요 2건"

코드 실행이 꺼져 있으면 같은 열 순서의 표를 대화창에 그려 주고, "설정 → 기능에서 코드 실행 및 파일 생성을 켜면 엑셀로 받을 수 있어요"라고 안내한다.

## 3단계: 카드 내역과 대조해서 빠진 경비 찾기

사용자가 카드사 이용내역(엑셀·CSV)을 올리면 한다. 카드사마다 열 이름이 달라서 스크립트가 "이용일/거래일/승인일", "가맹점/이용가맹점/가맹점명", "이용금액/승인금액/금액" 같은 이름을 알아서 찾는다. 못 찾으면 사용자에게 어느 열이 날짜·가맹점·금액인지 물어본다.

```
python scripts/match_card.py 장부.xlsx 카드내역.xlsx 대조결과.xlsx
```

- 날짜 ±3일, 금액이 같으면 같은 거래로 본다.
- 결과 시트
  - **장부에 없음**: 카드로 결제했는데 영수증·장부에 없는 건 → "빠진 경비 후보"
  - **카드에 없음**: 장부에는 있는데 카드 내역에 없는 건 → 현금·다른 카드인지 확인
  - **매칭됨**: 양쪽에 다 있는 건
- 대화창에는 "빠진 경비 후보 N건, 합계 ○○원"과 상위 5건만 보여 준다.
- 빠진 경비 후보마다 "사업용이면 장부에 추가하고, 카드 내역이나 전표를 증빙으로 보관하세요"라고 안내한다. 사업용인지는 사용자가 정한다. 사용자가 "추가해줘"라고 하면 그 건을 장부에 넣고 엑셀을 다시 만든다.

## 지켜야 할 것

- 숫자를 지어내지 않는다. 안 보이면 빈칸 + 확인필요.
- 세금을 얼마 아낀다고 단정하지 않는다. "빠진 경비를 찾는다"까지만 말한다.
- 비용 인정, 부가세 공제, 신고 방법 같은 판단은 "최종 신고 전에 홈택스 안내나 세무사에게 확인하세요"라고 덧붙인다.
- 장부 파일에 카드번호 전체·주민번호·사업자번호를 넣지 않는다.
