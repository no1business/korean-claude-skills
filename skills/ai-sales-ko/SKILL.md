# 한국판 AI 영업사원 (ai-sales-ko)

방구석프로 제작 · MIT. 흐름은 [ethanplusai/harvey](https://github.com/ethanplusai/harvey)(MIT)를 참고해 한국 B2B에 맞게 새로 만들었다.

```
상품 한 줄 → 채용공고에서 회사 찾기 → 회사별 제안 메일 → 승인/자동 발송(하루 상한) → 답장 읽기·분류 → 답장·미팅 제안
```

모든 데이터는 작업 폴더 `sales/` 안에 파일로 남긴다. 사용자는 언제든 열어볼 수 있다.

| 파일 | 내용 |
|---|---|
| `sales/config.json` | 상품·보내는 사람·메일 계정·발송 규칙 |
| `sales/leads.csv` | 찾은 회사와 근거(공고 문구) |
| `sales/outbox/*.json` | 회사별 메일 초안. `status`: draft → approved → sent |
| `sales/replies/*.json` | 받은 답장과 분류 결과 |
| `sales/suppress.txt` | 다시 보내면 안 되는 주소(수신거부·반송) |
| `sales/STOP` | 이 파일이 있으면 모든 발송 즉시 중단 |

## 0단계 · 처음 설정 (한 번만)

1. 사용자에게 묻는다(한 번에):
   - 우리 상품을 한 줄로 (예: "기업용 AI 업무 자동화 세팅")
   - 어떤 회사가 고객인지 (예: "마케터 혼자 콘텐츠를 다 하는 중소기업")
   - 보내는 사람 이름·회사명·답장 받을 연락처
   - 미팅 가능한 시간대
   - 메일 계정: 네이버 또는 지메일
2. `python scripts/mailer.py init` 으로 `sales/config.json`을 만들고 답을 채운다.
3. **비밀번호는 클로드가 받거나 입력하지 않는다.** 사용자에게 아래를 안내하고, 사용자가 직접 터미널에서 환경변수를 설정하게 한다.
   - 지메일: Google 계정 → 보안 → 2단계 인증 켜기 → 앱 비밀번호 만들기
   - 네이버: 네이버 메일 → 환경설정 → POP3/IMAP 설정 → IMAP/SMTP 사용 켜기. 2단계 인증을 쓰면 애플리케이션 비밀번호를 만든다
   - 설정: `export SALES_APP_PASSWORD='앱비밀번호'` (윈도우 PowerShell: `$env:SALES_APP_PASSWORD='앱비밀번호'`)
4. `python scripts/mailer.py check` 로 로그인만 확인한다(메일은 보내지 않는다).
5. **영업 전용 새 계정**을 쓰라고 권한다. 평소 쓰는 주 계정이 스팸 신고를 받으면 업무 메일까지 막힌다.

## 1단계 · 잠재고객 찾기 (채용공고)

채용공고는 "지금 이 일을 사람 손으로 하고 있다"는 가장 확실한 신호다. 마케터·콘텐츠·사무 공고를 낸 회사는 자동화 제안을 받을 이유가 분명하다.

1. 브라우저 도구(클로드 인 크롬 또는 내장 브라우저)로 사람인·잡코리아·원티드 등에서 상품과 맞는 키워드로 검색한다. 예: `마케터 SNS 콘텐츠 블로그`.
2. **사람이 보는 속도로, 한 번에 10~20건만** 연다. 대량 수집(크롤링)은 하지 않는다. 사이트 약관 위반이 될 수 있다.
3. 공고마다 아래만 뽑아 `sales/leads.csv`에 추가한다:
   `company,region,job_title,duties,quote,posting_url,contact_email,email_source`
   - `duties`: 주요 업무 3~5개 (공고 문구 그대로 요약)
   - `quote`: 회사가 직접 쓴 한 문장 (예: "기업·사무실 이사 분야를 본격적으로 키우려고")
   - `contact_email`: **공고나 회사 홈페이지에 공개된 담당자·대표 메일만.** 추측해서 만든 주소(이름@회사.com)는 쓰지 않는다. 없으면 비워 두고 "메일 없음"으로 표시한다
   - `email_source`: 그 메일을 어디서 봤는지 (공고 URL 또는 홈페이지 URL)
4. 상품과 안 맞는 회사(대행사가 다 해주는 곳, 대기업 공채 등)는 넣지 않는다. 몇 건을 왜 뺐는지 한 줄로 알려준다.

## 2단계 · 회사별 제안 메일 쓰기

`references/writer.md` 규칙을 그대로 따른다. 핵심:

- 첫 문장에 **회사 이름 + 그 회사 공고에서 본 사실**을 넣는다. 이게 스팸과 제안을 가르는 기준이다.
- 첫 메일엔 가격·할인·"무료" 없음. 7문장 이하, 느낌표·이모지 없음.
- "채용과 별개로" 반복 업무 일부를 덜어드리는 제안으로 쓴다. 사람을 대체한다고 쓰지 않는다.
- 마지막은 답하기 쉬운 질문 하나.

회사마다 `sales/outbox/<번호>_<회사>.json`을 만든다:
```json
{"to":"...","company":"...","subject":"...","body":"...","evidence":"공고에서 쓴 근거 문장","status":"draft"}
```
다 쓰면 초안 3개를 사용자에게 보여주고 톤을 확인받는다.

## 3단계 · 보내기

`python scripts/mailer.py send` 가 `status`가 `approved`인 메일만 보낸다(`config.require_approval`가 false면 `draft`도 보냄).

스크립트가 자동으로 지키는 것:
- **하루 상한**: 계정을 처음 쓰면 1일 5통 → 8 → 12 → 15 → 20통으로 천천히 늘린다(`warmup`). 상한을 넘으면 다음 날로 미룬다.
- **발송 시간대**: 평일 09~18시만. 메일 사이 3~9분 무작위 간격.
- `suppress.txt`에 있는 주소, 이미 보낸 회사, 같은 도메인 중복은 건너뛴다.
- `sales/STOP` 파일이 있으면 즉시 멈춘다.
- 모든 메일 끝에 수신거부 안내 한 줄을 붙인다.

**처음에는 `require_approval: true`로 시작한다.** 사용자가 초안을 보고 "승인"이라고 하면 그 파일의 status를 approved로 바꾼다. 10~20통 정도 답장 반응을 보고 사용자가 원할 때만 false(완전 자동)로 바꾼다.

계속 돌리려면 `python scripts/mailer.py run` (발송 → 답장 확인을 시간대 안에서 반복, Ctrl+C로 종료). 컴퓨터가 켜져 있어야 한다.

## 4단계 · 답장 읽고 답하기

1. `python scripts/mailer.py inbox` → 새 답장을 `sales/replies/`에 저장한다.
2. 각 답장을 `references/handler.md` 기준으로 분류하고 답장 초안을 `reply` 필드에 쓴다.
   - 관심·질문 → 질문에 답하고 미팅 시간 2~3개 제안
   - 반대 의견 → 한 번만 짧게 답하고 질문으로 끝
   - 담당자 아님 → 감사 인사 + 맞는 담당자 소개 부탁
   - 거절·수신거부 → **답장하지 않고** `suppress.txt`에 추가
   - 화남·법적 언급 → 답장하지 않고 사용자에게 바로 알림
3. 가격·계약 조건은 지어내지 않는다. config에 없으면 "통화에서 범위에 맞춰 안내"로 쓴다.
4. `python scripts/mailer.py reply` 가 승인된 답장을 원래 메일 스레드로 보낸다.
5. 미팅이 잡히면 사용자에게 회사·시간·내용을 한 줄로 보고한다. 캘린더 도구가 연결돼 있으면 일정 추가를 제안한다.

## 지켜야 할 것

`references/safety.md`를 첫 발송 전에 사용자와 한 번 같이 읽는다. 요약:
- 법인 대표·담당 메일이어도 광고성 정보로 볼 여지가 있다. 제목·본문 표기와 수신거부 방법은 KISA 「불법스팸 방지를 위한 정보통신망법 안내서」 최신판을 사용자가 직접 확인하게 한다. 클로드는 법률 판단을 하지 않는다.
- 공개되지 않은 개인 메일, 추측한 주소, 구매한 메일 목록은 쓰지 않는다.
- 반송률이 5%를 넘거나 스팸 신고가 1건이라도 생기면 `STOP`을 만들고 사용자에게 알린다.
